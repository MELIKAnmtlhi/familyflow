# 🏠 FamilyFlow

> All-in-one family management app built with Next.js & MongoDB

FamilyFlow helps families stay organized — manage tasks, track expenses, save memories, and plan events, all in one place.

---

## ✨ Features

- 🔐 Authentication — Secure login with Google (NextAuth.js)
- 📊 Dashboard — Real-time overview of tasks and budget
- 👨‍👩‍👧‍👦 Member Management — Add and manage family members
- 📋 Task Management — Weekly plans and daily tasks
- 💰 Budget Tracking — Track expenses by category and member
- 📈 Reports & Charts — Visual insights with Recharts
- 📅 Calendar — Never miss birthdays or events
- 🔔 Notifications — Stay updated on family activities
- 🎨 Modern UI — Clean design with smooth animations
- 📱 Responsive — Works on all devices

---

| Category | Technologies |

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- MongoDB Atlas account
- Google Cloud Console account (for OAuth)

- ### Installation

1. Clone the repository

bash
git clone https://github.com/MELIKAnmthii/familyflow.git
cd familyflow/my-app


2. Install dependencies

bash
npm install


3. **Create .env file**

env
MONGO_USER=your_username
MONGO_PASS=your_password
MONGO_URI=mongodb+srv://...

AUTH_SECRET=your_secret_key
AUTH_GOOGLE_ID=your_google_client_id
AUTH_GOOGLE_SECRET=your_google_client_secret

4. Run the development server

bash
npm run dev


5. Open (http://localhost:3000)
